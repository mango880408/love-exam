# 📋 프로젝트 기획서: 연애능력평가 - 여친/남친 고사 (Love Exam)

## 1. 프로젝트 개요
- **서비스명:** 제1회 여친/남친 탐구영역 모의고사 (Love Exam)
- **목적:** 연인끼리 자신에 대한 문제를 직접 출제(중간고사/기말고사 형식)하고 링크로 공유하여 풀어보게 하는 바이럴 웹 서비스
- **핵심 타겟:** 10대~30대 커플, 기념일이나 일상에서 색다른 재미 요소를 찾는 연인
- **수익 모델:** 무료 이용 기반 + 웹사이트 좌/우측 스카이스크래퍼 배너 광고 및 모바일 상/하단/결과창 인피드 광고 (Google AdSense 등 연동 구조)

---

## 2. 비주얼 & UI/UX 컨셉 ("100% 한국 시험지 감성")
1. **시험지 질감 및 레이아웃**
   - 실제 수능 및 학교 지필고사에서 사용하는 미색 갱지(`#f6f3ec`) 배경과 검은색 이중 테두리선, 중앙 세로 단 구분선 연출
   - 명조체(바탕체, `Nanum Myeongjo` / `Noto Serif KR`) 기반의 문제 타이포그래피와 굵은 고딕(`Noto Sans KR`) 헤더 조합
2. **시험지 디테일 요소**
   - 상단 교시/영역 표기 (`제 1 교시 | 남친/여친 탐구 영역`), 시험 종류(`중간고사` / `기말고사` / `모의평가`), `수험번호` 및 `성명` 기입란
   - 원문자 선택지(`① ② ③ ④ ⑤`) 및 클릭 시 빨간색 컴퓨터용 사인펜/채점펜 마킹 효과
3. **채점 및 성적표 연출**
   - 시험지 우측 상단에 손글씨 느낌의 **빨간펜 점수 기록 및 동그라미/빗금 표시**
   - 문제별 빨간펜 **동그라미(O)** / **체크(✓)** 채점 흔적 및 정답 공개
   - 등급 산출 (1등급 ~ 9등급) 및 등급별 도장(`참 잘했어요`, `사랑꾼 인증`, `재수강 요망`, `야간자율학습 확정`)

## 3. 핵심 기능 명세
1. **출제자 모드 (선생님 모드)**
   - 출제자 이름, 시험 구분(중간고사/기말고사/수능특집), 목표 커트라인 점수 설정
   - **객관식(4지선다)** 및 **주관식(단답형)** 자유 혼합 출제
   - 문항별 배점 자동/수동 계산 및 해설(맞혔을 때/틀렸을 때 한마디) 입력
   - **추천 문제 자판기:** 출제가 막막한 사용자를 위해 카테고리별 추천 질문 원클릭 삽입
2. **링크 공유 시스템 (Serverless URL 인코딩 방식)**
   - 별도 회원가입이나 DB 서버 없이도 즉시 테스트 및 공유가 가능하도록 출제 데이터를 압축/인코딩하여 URL 파라미터(`?exam=...`)로 생성
   - 카카오톡, 인스타그램 DM 등으로 링크만 보내면 상대방이 어디서든 즉시 응시 가능
3. **수험생 모드 (응시 화면)**
   - 수험생 성명 및 사귄 기간(또는 수험번호) 입력 후 시험 시작
   - 한국 시험지 스타일의 문제 풀이 UI 및 미입력 문항 안내
4. **자동 채점 & 성적표 & 바이럴 루프**
   - 객관식 번호 일치 및 주관식(공백 제거/대소문자 무시/복수 정답 지원) 자동 채점
   - 성적표 공유하기 및 **"나도 문제 내서 복수하기 (출제하러 가기)"** 버튼을 통한 연쇄 바이럴 유도

## 4. 광고(수익화) 레이아웃 설계
- **데스크톱 (PC):** 중앙에 A4 비율의 시험지 컨테이너를 배치하고, 좌측/우측 여백에 `160x600` (Wide Skyscraper) 고정형 배너 광고 슬롯 배치 (`slotAllocation`을 통해 슬롯별 플랫폼 지정 가능)
- **모바일/태블릿:** 화면 폭이 좁아지면 상단(`#adMobileTopSlot`)·하단(`#adMobileBottomSlot`) 고정 띠배너(`320x50` / `320x100`) 및 채점 결과 하단 네이티브 배너로 자동 전환되는 반응형 구조
- **통합 멀티 플랫폼 수익화 연동 (`ad-config.js`, `app.js`, `coupang_api_server.py`):**
  - **쿠팡 파트너스 (Coupang Partners):** 공식 다이나믹/카테고리 배너 위젯 ID(iframe) 노출 또는 출제자 정답 키워드 기반 로켓배송·로켓선물 맞춤 상품 배너 & Open API 검색 프록시 지원
  - **1020 패션·여성복·뷰티 파트너스:** 무신사 큐레이터(`MUSINSA`), 지그재그(`ZIGZAG`), 에이블리(`ABLY`), 올리브영 어필리에이트(`OLIVE YOUNG`), `29CM` 상품을 출제자 정답 키워드(커플룩, 데이트룩, 향수, 커플링, 19+ 시크릿 케어/파자마 등)와 자동 매칭하여 브랜드별 전용 배지·배송 태그(`⚡ 직진배송`, `🛵 오늘드림`, `⚡ 샥출발` 등)와 함께 노출
  - **CPC 클릭형 네트워크 (Google AdSense & Kakao AdFit):** 구글 애드센스(19+ 모드 진입 시 계정 보호를 위해 파트너스/애드핏으로 자동 폴백) 및 카카오 애드핏(`DAN-...` 단위 ID) 스크립트 자동 로드 및 채점 결과창 하단 하이브리드 노출 지원

## 5. 폴더 및 파일 구조 (`love_exam/`)
- `index.html` : 메인 시험지 레이아웃, 빨간 색연필 질감 SVG 필터(`#red-pencil-texture`), 좌/우 사이드바 및 모바일 상/하단 광고 슬롯
- `styles.css` : 한국 시험지(미색 갱지, 이중 테두리, 2단 단 구분선), 19+ 다크/와인 테마(`.spicy-theme`), 손글씨 채점/도장 스타일, 멀티 파트너스 위젯 스타일
- `app.js` :
  - **과목 구성:** 제1교시 기본 탐구영역(필수) + 제2교시 19+ 성적취향 탐구영역(선택, 성인 확인 게이트 포함)
  - **추천 문제 자판기:** 기본/19+ 카테고리별 프리셋 문항, 유사 질문 클러스터링, 실시간 출제/오답률 통계 표시
  - **공유 & 채점 결과 회신:** URL 파라미터(`?exam=...`) 기반 서버리스 시험지 공유 및 수험생 채점 답안지 역공유 링크(`&result=...`), 실시간 답안지 수신함(`localStorage` / `BroadcastChannel`)
  - **통합 광고 & 파트너스 엔진:** 슬롯별 배정(`slotAllocation`) 기반 쿠팡 / 1020 패션·뷰티(무신사·지그재그·에이블리·올리브영·29CM) / 구글 애드센스 / 카카오 애드핏 렌더링
- `ad-config.js` : 슬롯별 플랫폼 배정, 애드센스·애드핏·쿠팡·1020 파트너스 제휴 코드, 정답 키워드별 멀티 플랫폼 추천 상품 카탈로그 설정
- `coupang_api_server.py` : 로컬 웹 서버(`http://localhost:8080`) 겸 쿠팡 파트너스 Open API(HMAC 서명) 검색 프록시 서버
- `ads.txt` : 광고 플랫폼 인증용 텍스트 파일

1. AI에게 **"연인고사 페이지 이어서 작업하자"** 또는 **"서버 켜줘"**라고 요청

   ```bash
   python3 love_exam/coupang_api_server.py
   ```
   실행 후 브라우저에서 `http://localhost:8080` 접속 (또는 `love_exam/index.html` 직접 열기)
